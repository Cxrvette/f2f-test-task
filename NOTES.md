# F2F Bank — замечания по результатам E2E-анализа

## Критический дефект: перевод не зачисляется получателю

В модели регистрации отсутствует номер телефона, а API `POST /api/users/transfer`
не ищет получателя. Сервис проверяет лишь формат переданной строки и списывает
сумму с баланса отправителя. Поэтому бизнес-сценарий «User A переводит User B,
баланс B увеличивается» в текущей реализации проверить невозможно.

## Ограничение истории транзакций

История показывает сумму, тип и статус операции, но не показывает получателя и
назначение платежа. Проверка этих полей в E2E-тесте невозможна.

## Ошибка подписей таблицы

Значения типа и статуса транзакции выведены под противоположными заголовками:
в колонке `Operation Type` отображается статус, а в `Operation Status` — тип.

## Проверка некорректного пополнения

UI молча оставляет модальное окно открытым для нулевой и отрицательной суммы.
Баланс не меняется, но пользователь не получает понятного сообщения об ошибке.
